# Vue 3 项目文档

## 项目概述
这是一个基于 Vue 3 + TypeScript 开发的前端项目，使用了最新的组合式 API 和 `<script setup>` 语法。

## 技术栈
- Vue 3
- TypeScript
- Pinia (状态管理)
- Vue Router (假设使用)

- 📝 文章展示与管理

- 🔍 文章搜索功能
- 💬 评论系统
- 📱 响应式设计
- 🌙 深色模式支持

## 💻 开发指南

- 组件开发使用 Vue 3 `<script setup>` 语法，详见 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html)
- 状态管理使用 Pinia，详见 [Pinia 文档](https://pinia.vuejs.org/)
- 样式采用 TailwindCSS，详见 [TailwindCSS 文档](https://tailwindcss.com/docs)
- 提交代码前请运行 `npm run lint` 进行代码规范检查

## 🔧 环境要求

- Node.js >= 16.0.0
- npm >= 7.0.0 或 yarn >= 1.22.0
- 现代浏览器支持
